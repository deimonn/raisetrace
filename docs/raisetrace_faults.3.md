# Name

raisetrace_faults, raisetrace_unhandled - predefined signal/exception lists for raisetrace

# Synopsis

```C
#include <raisetrace.h>

extern const int raisetrace_faults[];

extern const int raisetrace_unhandled[];
```

# Description

**raisetrace_faults** and **raisetrace_unhandled** are supplementary predefined lists of signal numbers/exception codes for passing to [**raisetrace**(3)](raisetrace.3.md):

+ **raisetrace_faults**

  Contains signals or exceptions generated due to severe program faults, such as division by zero or segmentation faults/access violations.

  By default these terminate the program abnormally, possibly with additional actions (usually a core dump).

+ **raisetrace_unhandled**

  Contains signals generated by timers, sockets or by the user. Empty on Windows.

  By default these terminate the program abnormally when unhandled, but do not invoke additional actions.

For most programs, **raisetrace_faults** will be enough. **raisetrace_unhandled** is useful if you wish to catch all cases of unhandled terminating signals.
