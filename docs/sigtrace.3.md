# Name

sigtrace, sigtrace_faults, sigtrace_unhandled - print siginfo and stack trace on signal

# Synopsis

```C
#include <sigtrace.h>

extern const int sigtrace_faults[];

extern const int sigtrace_unhandled[];

int sigtrace(const int *siglist);
```

# Description

**sigtrace**() installs a signal handler via **sigaction**(2) for each of the signals specified in _siglist_. The _siglist_ array must be zero-terminated.

The handler will print signal information via **psiginfo**(3) and, when the platform supports it, follow it with a full stack trace. Afterwards, the handler simply performs the default action for the signal.

The installed handlers are not special in any way and may be overriden or reinstated again at any point for any given signal, but note that this function is not thread-safe nor guaranteed to be async-signal-safe, so this is probably best done during program initialization.

**sigtrace_faults** and **sigtrace_unhandled** are supplementary predefined lists of signals:

+ **sigtrace_faults**

  Contains signals generated due to severe program faults, such as division by zero or segmentation faults.

  By default these terminate the program abnormally with additional actions (usually a core dump).

+ **sigtrace_unhandled**

  Contains signals generated by timers, sockets or by the user.

  By default these terminate the program abnormally when unhandled, but do not invoke additional actions.

For most programs, **sigtrace_faults** will be enough. **sigtrace_unhandled** is useful if you wish to catch all cases of unhandled terminating signals.

# Return value

Returns 0 on success, a negative error number on failure.

# Errors

+ **-EINVAL**

  One or more values in _siglist_ either aren't a valid signal number, or represent a signal that cannot be caught. Rest of signals, if any, will still have been processed correctly.

Note that all error codes are negated. To convert them to regular **errno**(3) values for comparison or passing to **strerror**(3), apply unary negation on the return value first.
