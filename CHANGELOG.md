# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased](https://github.com/deimonn/raisetrace/compare/0.1.0...HEAD)

### Changed

- Library redubbed from **sigtrace** to **raisetrace** to properly signal scope change and expansion, including a rename of all concerned symbols
- **raisetrace**() (formerly **sigtrace**()) now returns errors as negative numbers instead of setting errno
