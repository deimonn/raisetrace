# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased](https://github.com/deimonn/raisetrace/compare/0.1.0...HEAD)

### Added

- Added a new optional callback **raisetrace_callback** that is invoked in place of the default handling logic and can be used to perform a custom action or simply print to a different stream when a raised signal or exception is caught
- Added support for building and using the library on Windows

### Changed

- Library redubbed from **sigtrace** to **raisetrace** to properly signal scope change and expansion, including a rename of all concerned symbols
- **raisetrace**() (formerly **sigtrace**()) now returns errors as negative numbers instead of setting errno
- Signal messages are now generated by **raisetrace** itself rather than via **psiginfo**(3); this means that only standard signals are recognized and that the messages will always be in english, but this opens up the ability to write such messages to any stream rather than being restricted to standard error
